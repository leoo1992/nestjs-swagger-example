# NestJS Swagger Example

An example API built with NestJS to demonstrate module organization and HTTP endpoints documented with OpenAPI/Swagger.

## Stack
- Node.js and TypeScript
- NestJS 9
- @nestjs/swagger and Swagger UI
- Jest and Supertest

## Run

```bash
npm install
npm run start:dev
```

Run tests with `npm test` and build with `npm run build`. Check `src/main.ts` for the configured Swagger documentation path.
