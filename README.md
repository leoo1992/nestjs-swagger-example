# NestJS Swagger Example

API de exemplo construída com NestJS para demonstrar a organização de módulos e endpoints HTTP com documentação OpenAPI/Swagger.

## Stack
- Node.js e TypeScript
- NestJS 9
- @nestjs/swagger e Swagger UI
- Jest e Supertest

## Como executar

```bash
npm install
npm run start:dev
```

Execute os testes com `npm test` e a compilação com `npm run build`. Consulte `src/main.ts` para o caminho configurado para a documentação Swagger.
